= Engineering above the model

The model is the base of the stack, but it is only the base. Everything that
turns a raw model into a reliable tool is engineering layered on top of it. Four
such layers sit above the model, each the subject of its own section in this
standard.

Working outward from the model:

* *Tuning model behavior* controls _how_ the model samples its output — the
  inference-time parameters that shape determinism, length, creativity, and
  depth of reasoning, without changing the model or its input.

* *Context engineering* controls _what the model sees_ — the tokens placed in
  its working memory on each call: instructions, retrieved knowledge, tool
  definitions, and conversation history.

* *Harness engineering* controls _the environment the model runs in_ — the
  tools, guardrails, and sensors that determine what an agent can and cannot do.

* *Loop engineering* controls _how the whole workflow runs itself_ — automating
  a process end to end, so it wakes on a schedule, discovers its own work, and
  feeds its own output back as the next input.

Each layer adds control over the one below it, and each sits progressively
further from the model itself. The rest of this standard works through them in
turn — first the model and the interface you run it through, then each
engineering layer in depth.
