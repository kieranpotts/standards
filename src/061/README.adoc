= TS-61: AI Tools
:toc: macro
:toc-title: Contents

This technical standard covers best practices for using AI tools in software
development workflows.

The acronyms LLM and AI are used interchangeably throughout. The subject is AI
tools based around large language models models that are themselves based on the
transformer architecture, or similar.

The scope of this technical standard runs from choosing a model and an interface,
through harness and context engineering and the design of AI-assisted and
agentic workflows, to evaluation, cost optimization, and security.
