= TS-61: AI Tools
:toc: macro
:toc-title: Contents

This technical standard covers best practices for using AI tools in software
development workflows — specifically, the generation of program code,
architectural designs, and technical documentation.

The acronyms LLM and AI are used interchangeably throughout. The subject is AI
models based on the transformer architecture, or similar.

The scope runs from choosing a model and an interface, through context
engineering and the design of AI-assisted and agentic workflows, to evaluation,
cost optimization, and security.
