= TS-61: AI Tools
:toc: macro
:toc-title: Contents

This technical standard covers best practices for using AI tools in software
development workflows.

The acronyms LLM and AI are used interchangeably throughout. The subject is AI
tools based around large language models models that are themselves based on the
transformer architecture, or similar.

NOTE: "AI tools" is not one technology. It covers a range of technologies,
including harnesses and user interfaces, built around many different models
and providers. The common factor across all of them is a large language model
at the core.

The scope of this technical standard runs from choosing a model and an interface,
through harness and context engineering and the design of AI-assisted and
agentic workflows, to evaluation, cost optimization, and security.

Beneath every one of those practices is a single problem. A large language model
is inherently unpredictable and unreliable — confidently wrong some fraction of
the time, and never quite the same twice — and yet the work must be made to hold.
Everything that follows is, at bottom, one discipline: bending a tool of this kind
to serve reliable ends without ever trusting it to.
