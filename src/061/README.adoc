= TS-61: AI Tools
:toc: macro
:toc-title: Contents

This technical standard covers best practices for using AI tools to support software development workflows – specifically, the generation of computer program code, software architectural designs, and technical documentation.

In this technical standard, the acronyms LLM and AI are used interchangeably, but know that the topic is AI models based on the transformer (or similar) architecture.

Topics covered include:

* The role of human judgment in AI-assisted development.
* Understanding AI model capabilities and limitations.
* Choosing the right interface for the task – specialist tools vs. general-purpose chatbots.
* Task segmentation and workflow optimization.
* Context engineering and knowledge documentation.
* Cost optimization techniques.
* Security and risk considerations.
* Testing strategies for AI-generated code.
