= Line length and wrapping

Long lines SHOULD be "soft wrapped" at 80 characters — that is, continued on the
next line without any special line-break syntax. Adjacent lines within an
AsciiDoc paragraph are combined into a single line in the rendered output, so
soft wrapping does not affect how the document renders. See
*link:./11-preserving-line-breaks.adoc[Preserving line breaks]* for how to force
an actual line break where one is needed.

The purpose of this constraint is to ensure that files render identically in
every editor, regardless of the editor's own line-wrapping width or settings.

Lines MUST NOT exceed 160 characters, except where this cannot be achieved — for
example, in tables or long URLs that cannot themselves be broken across lines.

A soft wrap MUST NOT be inserted within an inline formatting unit, such as bold
or italic text, so as to preserve the formatting markers (eg. `*` or `_`)
alongside the text they format.
