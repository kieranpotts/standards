= Lists

To create a list, prefix each item in the list with the `*` sign followed by a single space.

To created nested lists, use multiple `*` signs according to the nesting level.

[NOTE]
======
AsciiDoctor also supports the hyphen (`-`) as a Markdown-style list marker, but it is not used in these standards. The hyphen does not support nested lists: indentation-based nesting, as used in Markdown, produces a flat list in AsciiDoc rather than a nested one. Nested lists require the repeated-asterisk marker (`**`, `***`, and so on). Using `*` consistently for all levels keeps the marker length equal to the nesting level, which is the AsciiDoc convention and remains readable as plain text.
======

When list items contain more than one line of text, indent the subsequent lines by at least one space to make it clear that they belong to the same list item. In addition, leave a blank line before the next item.

```
* level 1
** level 2
*** level 3
**** level 4
***** level 5
* level 1
```

For guidance on when to use numbered versus bulleted lists, and on punctuation and parallelism within list items, see *link:../026/README.adoc[TS-26: Technical Writing Style Guide]*.
