:link-google-research-zanzibar-2019: https://research.google/pubs/zanzibar-googles-consistent-global-authorization-system/

This technical standard covers the architecture of authentication and
authorization: the choice between session- and token-based authentication,
OAuth 2.0 and OpenID Connect, single sign-on and federation, multi-factor
authentication, authorization models (RBAC, ABAC, ReBAC), and
service-to-service authentication.

It does not cover the credential and secrets-handling rules that apply
regardless of architecture — password strength, hashing, re-authentication,
and least-privilege access verification — which are set out in
xref:052.adoc[*TS-52: Security and secrets management*]. Nor does it cover
JWT schema design, which is xref:056.adoc[*TS-56: JSON Web Tokens (JWTs)*].
For how an HTTP API transmits credentials on the wire, see
xref:021.adoc[*TS-21: HTTP APIs*].

== References

* IETF (2012).
  {link-ietf-rfc6749-2012}[_RFC 6749: The OAuth 2.0 Authorization Framework_].
  — The base specification for the grant types and roles described in <<OAuth 2.0 and OpenID Connect>>.

* IETF (2024).
  {link-ietf-rfc9700-2024}[_RFC 9700: Best Current Practice for OAuth 2.0 Security_].
  — The source for the authorization-code-with-PKCE recommendation and the deprecation of the
  implicit and password grants.

* OpenID Foundation (2014).
  {link-openid-connect-core-2014}[_OpenID Connect Core 1.0_].
  — The specification for the `id_token` and discovery mechanism described in <<OAuth 2.0 and OpenID Connect>>.

* IETF (2011).
  {link-ietf-rfc6238-2011}[_RFC 6238: TOTP: Time-Based One-Time Password Algorithm_].
  — The source for the TOTP factor described in <<Multi-factor authentication>>.

* W3C (2021).
  {link-w3c-webauthn-2021}[_Web Authentication: An API for accessing Public Key Credentials Level 2_].
  — The specification behind the passkey factor described in <<Multi-factor authentication>>.

* Google Research (2019).
  {link-google-research-zanzibar-2019}[_Zanzibar: Google's Consistent, Global Authorization System_].
  — The reference design for the relationship-based access control model described in
  <<Authorization models>>.
