= TS-26: Technical writing style guide
:toc: macro
:toc-title: Contents

This technical standard covers _how_ to write technical documentation. Topics
include voice and tense, headings, terminology, formatting conventions, and
other prose-level and presentational rules that apply within any individual
document.

For _what_ documentation a project should have, _where_ it lives, _who_ it's
for, and how it's kept current, see
xref:025.adoc[*TS-25: Technical documentation*].
