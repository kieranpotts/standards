= TS-11: Versioning
:toc: macro
:toc-title: Contents

Software components that are released, distributed, or otherwise consumed by
other parties — including libraries, web services, end-user applications,
command-line tools, and infrastructure modules — SHOULD use a consistent
versioning scheme for their releases. This makes it easier to manage
compatibility between components and to communicate changes to consumers.
