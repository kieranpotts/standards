= TS-41: React
:toc: macro
:toc-title: Contents

This technical standard covers best practices for working with React, a popular JavaScript library used for composing
graphical user interfaces from reusable components. The guidance here is written for React on the web, but the
component, state, and filesystem conventions apply to React's other render targets too. See <<Cross-platform React>>
for sharing one codebase between a web application and native mobile applications.
