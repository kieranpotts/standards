= TS-34: PHP
:toc: macro
:toc-title: Contents

PHP code MUST follow the
https://www.php-fig.org/per/coding-style/[PER Coding Style v2.0], published by
the PHP Framework Interop Group (PHP-FIG). PER Coding Style is the definitive
standard for PHP coding style. This technical standard summarizes and extends
it, but where this standard is silent, PER Coding Style is authoritative.
