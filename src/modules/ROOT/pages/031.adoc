= TS-31: Unix shells and POSIX standards
:toc: macro
:toc-title: Contents

This technical standard covers best practices for writing Unix shell scripts for
the purposes of system administration, batch processing, and other low-level
automation tasks.

See also xref:032.adoc[*TS-32: Bash*] for extended technical standards
for the Bash shell specifically. See also xref:062.adoc[*TS-62: Make*]
for guidance on Makefiles, which commonly wrap shell scripts and recipes
covered by this standard.
