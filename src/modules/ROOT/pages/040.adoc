= TS-40: CSS
:toc: macro
:toc-title: Contents

This technical standard specifies a CSS architecture — a design methodology built on user-land conventions such
as BEM, SMACSS, and OOCSS — that helps control the cascade and produce maintainable, scalable user interfaces.

It defines naming conventions and a system for separating the different concerns of a web interface: layout,
elements, components, and modifiers.

The CSS architecture described herein applies equally whether stylesheets are hand-written, compiled from a
preprocessor like Sass or Less, or generated by a CSS-in-JS framework.

== References

* Frost, B (2013).
  https://bradfrostweb.com/blog/post/atomic-web-design/[_Atomic Web Design_]. — A methodology for thinking about
  interfaces as a hierarchy of progressively more complex objects.

* Yandex. https://bem.info[_Block Element Modifier (BEM)_]. — A widely adopted class naming convention.

* Snook, J.
  http://smacss.com[_Scalable and Modular Architecture for CSS (SMACSS)_]. — A style guide covering base,
  layout, module, state, and theme rules.

* Gallagher, N. https://suitcss.github.io[_SUIT CSS_]. — A class naming convention combined with extended CSS
  syntax.

* Sullivan, N (2009).
  https://github.com/stubbornella/oocss[_Object-Oriented CSS (OOCSS)_]. — One of the earliest widely adopted web
  design methodologies.

* Roberts, H. https://cssguidelin.es[_CSS Guidelines_]. — A high-level advice document for writing sane,
  manageable CSS. Also the source for the `js-` JavaScript-hook-class fallback in <<Class names>>.

* Google.
  https://google.github.io/styleguide/htmlcssguide.html[_Google HTML/CSS Style Guide_]. — Formatting and naming
  conventions for HTML and CSS.

* Brown, T (2018). _CSS Master_. O'Reilly Media. — The source for the `@charset`, `@import`, and `box-sizing`
  guidance in <<Filesystem>>.

* Copes, F. _The CSS Handbook_. — The source for the `@import` media descriptor and print style sheet guidance
  in <<Filesystem>>.

* Painless CSS. https://painlesscss.com/top-10-css-mistakes.html[_Top 10 CSS Mistakes_]. — The source for the
  CSS-in-JS and CSS Modules scoping discussion in <<Overview>>.

* AllThingsSmitty. https://github.com/AllThingsSmitty/css-protips[_CSS Protips_]. — The source for the
  `unset`/`all` inheritance-keyword guidance in <<Embrace the constraints of the cascade>>.
