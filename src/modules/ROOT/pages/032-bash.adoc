= TS-32: Bash
:toc: macro
:toc-title: Contents

This technical standard extends
*xref:031-unix-shells-and-posix-standards.adoc[TS-31: Unix Shells and POSIX Standards]* with
guidelines for using the https://www.gnu.org/software/bash/[Bash shell]
specifically. Everything in TS-31 applies here, too; TS-32 extends TS-31.

See also *xref:062-make.adoc[TS-62: Make]* for guidance on Makefiles,
which commonly wrap Bash scripts and recipes covered by this standard.
