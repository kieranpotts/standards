== References

* Wiggins, A (2017).
  {link-wiggins-2017-logs}[_The Twelve-Factor App: XI. Logs_].
  — States that an app should never concern itself with routing or storage of its output stream; it should write
  unbuffered, timestamped events to `stdout` and let the execution environment handle capture, aggregation, and
  retention.

* Elhage, N (2020).
  {link-elhage-2020}[_Computers Can Be Understood_].
  — The source for <<Debugging as a discipline>> and <<When to stop deducing and start observing>>, on treating
  debugging as a systematic discipline and knowing when to switch from deductive to empirical investigation.

* Kosmulski, M (2024).
  {link-kosmulski-2024}[_Ten Years of Microservices at Allegro_].
  — The source for the self-service observability configuration guidance in <<Treat observability as a product>>.

* Orosz, G (2021).
  {link-orosz-2021}[_The Pragmatic Engineer Test_].
  — The source for the oncall health guidance in <<Oncall health>>.
