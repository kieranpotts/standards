= TS-9: Version control
:toc: macro
:toc-title: Contents

This technical standard covers the use of version control systems (VCS), also known as revision control, source control,
or source code management (SCM) systems.

This standard defines an opinionated workflow for shepherding the source code of software systems through the lifecycle
of development, testing, and release. This workflow is rooted in the principles of continuous integration and continuous
delivery – pillars of modern software development practices.
