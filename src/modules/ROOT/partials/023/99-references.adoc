// An effort to standardize event schemas, focused on interoperability across cloud providers and platforms. It specifies a generic specification for event data and metadata that can be mapped to a wide variety of messaging and transport protocols and message encoding formats. More opinionated than Standard Webhooks, and focused exclusively on message schema. As a protocol-agnostic standard, it does not cover security and authentication.

// An initiative to document common conventions for message delivery, targeting webhooks (event-oriented messages transmitted over the public internet between organizations), though many of the ideas apply to internal communication design, too. A catalog of the most common patterns in the webhook implementations of major public web services, specifying a standard based on those patterns and emerging best practices: event naming, payload structure, security (signatures), and delivery patterns.
* Standard Webhooks. {link-standard-webhooks}[_Standard Webhooks_].
