= Magic methods

PHP has class lifecycle hooks for attaching functionality in dynamic ways. These hooks are called magic methods.

While some application frameworks rely on magic methods to provide elegant ways for application code to interact
with the framework's functions, magic methods – by their nature – make code less explicit and therefore harder to
understand.

For this reason, application code SHOULD avoid using magic methods wherever possible. Prefer more direct execution
of framework-level logic, and define all your class methods explicitly.
