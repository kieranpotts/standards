[quote, Julio Biason]
____
Documentation is a love letter to your future self.
____

This technical standard covers _what_ documentation a software project should have, _where_ it should live, _who_ it is
for, and _how_ it stays trustworthy over time.

This technical standard is concerned with the informational architecture and lifecycle of documentation, not with
sentence-level writing style. For _how_ to write – voice, formatting, terminology, citations, and other prose-level
conventions that apply within any individual document – see xref:026.adoc[*TS-26: Technical writing style guide*].
