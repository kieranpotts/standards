This technical standard covers non-relational databases: the data models they offer (key-value, document,
wide-column, and graph), how to model data for them, the consistency and replication trade-offs specific to NoSQL,
and how to choose between a NoSQL engine and xref:043.adoc[TS-43] — or between
different NoSQL engines — for a given service. It does not repeat the ACID/BASE and CAP-theorem treatment already
covered in TS-43, nor the general distributed-data and caching guidance in
xref:046.adoc[TS-46]; it builds on both. For the mechanics of moving data between
database engines, see xref:045.adoc[TS-45].
