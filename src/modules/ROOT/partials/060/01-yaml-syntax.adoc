= YAML syntax

Actions and workflows are defined in YAML files. For general YAML syntax, quoting, indentation, and style conventions —
including why block-style sequences are RECOMMENDED over flow style for anything that changes over time, such as a
workflow's trigger branches — see xref:030.adoc[TS-30]. That standard's conventions apply in full to workflow
and action YAML files.

One workflow-specific case is worth calling out: the value of an `if` attribute is treated as a JavaScript expression
rather than a plain string, so YAML's own reserved characters can collide with expression syntax. See *<<Expressions>>*
below.
