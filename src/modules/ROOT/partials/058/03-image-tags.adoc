= Image tags

When creating images, it is RECOMMENDED to version them, and treat each version as immutable. Rather than deleting
images and replacing them with new ones, prefer to bump to a new version.

When consuming images, be explicit if you always want the latest version, even though `:latest` is the default tag:

----
FROM alpine:latest
----

However, using a specific version is best practice in most use cases. This will lock the container to a particular
version of an image, preventing unexpected breaking changes.

----
FROM nginx:1.23
----
