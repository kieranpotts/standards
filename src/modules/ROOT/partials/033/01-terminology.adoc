= Terminology

Throughout this document, the following words shall have the following meanings:

* "Class-like constructs" means any ordinary classes, enums, interfaces,
  records, or annotation types (`@interface`).

* "Block-like construct" refers to the body of a class, method, or constructor,
  and also to array initializers, static initializers, and other similar
  constructs.

* "Members" means all fields, methods, constructors, and nested classes within a
  class or other class-like structure.

* "Comments" refers only to _implementation_ comments, while "Javadoc" refers to
  inline _API documentation_ that is encoded as comments.
