= References

* https://www.youtube.com/watch?v=-Ln-8QM8KhQ[How is this website so fast?]
  (video) — Wes Bos reverse engineers the website for McMaster-Carr, a large
  industrial supply company, to show how they achieve fast page loads.
* https://aaardvarkaccessibility.com/wcag-plain-english/[WCAG in Plain English]
  — AAArdvark's beginner-friendly plain-English guide to the Web Content
  Accessibility Guidelines (WCAG), one success criterion at a time.
* https://www.jonoalderson.com/performance/youre-loading-fonts-wrong/[You're loading fonts wrong (and it's crippling your performance)]
  — Jono Alderson's deep dive into web font performance, covering formats,
  loading strategies, subsetting, fallbacks, and modern CSS descriptors.
* https://csswizardry.com/2019/08/time-to-first-byte-what-it-is-and-why-it-matters/[Time to First Byte: what it is and why it matters]
  — Harry Roberts on TTFB's contributors and the `Server-Timing` header. The
  source for <<Time to First Byte>>.
* https://www.bramstein.com/writing/web-font-loading-patterns.html[Web font loading patterns]
  — Bram Stein's catalog of font-loading techniques, including
  prioritised/sequential loading, `sessionStorage` caching, and JS-based
  loaders. The source for the loading-strategy additions in <<Fonts>>.
* https://web.dev/articles/top-cwv[Top Core Web Vitals recommendations for 2024]
  — web.dev on INP, layout thrashing, `contain`, `fetchpriority`,
  `loading="lazy"`, bfcache, and layout-inducing animations. The source for
  several items in <<Interaction responsiveness>>,
  <<reflows-repaints-and-layout-thrashing,Reflows, repaints, and layout
  thrashing>>, and <<Instant navigations>>.
* https://csswizardry.com/2024/12/a-layered-approach-to-speculation-rules/[A layered approach to Speculation Rules]
  — Harry Roberts on the Speculation Rules API's `prefetch`/`prerender`
  modes, eagerness levels, and the `Clear-Site-Data` cache-purge directives.
  The source for the Speculation Rules content in <<Instant navigations>>.
* https://expressionstatement.com/html-form-validation-is-heavily-underused[HTML form validation is heavily underused]
  — the case for the native constraint validation API. The source for the
  native-validation item in <<3. Understandable>>.
* https://css-tricks.com/tooltip-best-practices/[Tooltip best practices]
  — CSS-Tricks on accessible tooltip and toggletip implementation. The
  source for the expanded tooltip guidance in <<1. Perceivable>>.
* https://frontendmasters.com/blog/patterns-for-memory-efficient-dom-manipulation/[Patterns for memory-efficient DOM manipulation]
  — the source for the "Memory-efficient DOM manipulation" section of
  <<JavaScript behaviors>>.
* https://ricostacruz.com/rsjs/[rsjs — Reasonable System for JavaScript Structure]
  — Rico Sta. Cruz's convention for organizing client-side behavior code
  around DOM components. The source for the "Component behaviors" section
  of <<JavaScript behaviors>>.
* https://brandur.org/idempotency-keys[Implementing Stripe-like Idempotency Keys in Postgres]
  — Brandur Leppäkumpu's "Beyond APIs" section on the hidden-input
  double-submit-prevention pattern. The source for "Form submission
  integrity" in <<JavaScript behaviors>>.
* https://www.trysmudford.com/blog/hyper-responsive-web-components/[Hyper-responsive web components]
  — Trys Mudford on fluid typography, container queries, intrinsic layouts,
  and `text-wrap: balance`. The source for <<CSS layout and typography>>.
* https://www.neurodiversity.design/[Neurodiversity Design System] — design
  guidance for dyslexia, dyscalculia, ADHD, autism, and related neurotypes,
  drawn from its Font, Typography, Colour, Buttons/Links/Inputs, Interface,
  Numbers, Animations, and Communications principle pages. The source for
  <<5. Neurodiversity>>.
* https://webstyleguide.com/11-images.html[Images] — the Web Style Guide's
  chapter on image-format selection (GIF/JPEG/PNG/SVG), compression
  trade-offs, and alt-text conventions. The source for the format-selection
  guidance in <<Images>>.
* Weiss, Y, in _Real Life Responsive Web Design_ (Smashing Magazine, 2015),
  "Responsive Images" — the `srcset`/`sizes` attributes and the
  `<picture>` element for responsive image delivery. The source for the
  responsive-image-markup guidance in <<Images>>.
* Soueidan, S, in _Real Life Responsive Web Design_ (Smashing Magazine,
  2015), "Mastering SVG for Responsive Web Design" — the `<title>`/`<desc>`
  elements and the `role="img"`/`aria-labelledby` pattern for SVG
  accessibility. The source for the inline-SVG accessibility guidance in
  <<1. Perceivable>>.
