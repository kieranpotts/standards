= Placeholders

In code blocks, prefer to use angle brackets (`<>`) to encapsulate any placeholder text that is intended to be swapped for a value, such as a file name or a command line argument. Use square brackets (`[]`) to indicate optional arguments.

[source,sh]
----
./run <script> [<script-args>]
----

Follow the same convention in regular prose. For example, a URL containing a variable segment: `https://example.com/accounts/<account-id>/`.

Vary this rule where the placeholder syntax needs to match a formal grammar, for example a URI template per https://www.rfc-editor.org/rfc/rfc6570[RFC 6570], which uses curly braces rather than angle brackets. Example: `https://example.com/accounts/\{account_id}/`.
