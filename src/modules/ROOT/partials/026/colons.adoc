= Colons

Do not use a colon to introduce a code block or a list block. Where a sentence leads into a list, terminate the sentence with a period as normal.

Do not use a colon to join two independent clauses that could each stand as a sentence on their own. Instead, write them as separate sentences.

The only valid use for a colon is within a single sentence that ends with a short, comma-separated list.

----
The model supports three operations: create, read, and delete.
----

Lowercase the first word after a colon, unless it's a proper noun or the colon introduces more than one complete sentence.

----
The model supports three operations: create, read, and delete.
----
