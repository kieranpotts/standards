= Colons

Do not use a colon to introduce a code block or a list block. Where a sentence leads into a list, terminate the sentence with a period as normal.

Do not use a colon to join two independent clauses that could each stand as a sentence on their own. Instead, write them as separate sentences. Unlike a semicolon or a dash, a colon is never the exception described in Sentences and paragraphs.

Use a colon only in these cases. First, within a single sentence that ends with a short, comma-separated list. Second, after a one-word label that introduces an example, such as "Example:", "Bad:", or "Good:". A label is not a lead-in sentence, so the ban above on a colon before a list or code block does not apply to it. Third, after the key in a bold key-value lead-in, with the colon inside the bold markers, as TS-28 describes for lists.

----
The model supports three operations: create, read, and delete.
----

Lowercase the first word after a colon that ends a clause, unless it's a proper noun. After a label, follow the capitalization of the example itself.
