= Admonitions

An admonition, also known as a callout or boxout, is a block set apart from the surrounding prose, usually rendered as a labeled box or panel panel. The purpose is to separate out information that the reader could reasonably skip, without the main prose losing any meaning.

AsciiDoc has built-in admonition blocks, and some extensions of Markdown allow them. Where the format has no native support, work the information into the prose instead of imitating an admonition with ad-hoc formatting.

The five conventional admonition types, shared by AsciiDoc and GitHub-Flavored Markdown, are:

- *NOTE*: Supplementary information that adds context but isn't required to complete the task at hand.

- *TIP*: An optional suggestion that makes a task easier or faster.

- *IMPORTANT*: Information required to complete a task correctly.

- *WARNING*: An action or condition that could cause data loss, security exposure, or other ill effects.

- *CAUTION*: A risk of a less severe but still undesirable outcome.

(For the syntax, see xref:027.adoc[*TS-27: Markdown*] and xref:028.adoc[*TS-28: AsciiDoc*].)

Use admonitions sparingly. Used too often, they lose their utility. A document with an admonition between every paragraph trains readers to skip them all.

Use admonitions only for asides that are secondary to a linear read-through of the document. Do not use admonitions as a substitute for well-organized prose.
