= Grammatical person

Address the reader directly as "you" in instructional content ("run the following command") rather than an impersonal construction ("the user should run the following command"). This keeps instructions unambiguous about who is meant to act.

Avoid first-person plural ("we") to refer to a software system (or other product that is the subject of the technical documentation). Example: "the API returns an error", not "we return an error".

Reserve "we" for statements of the author's or team's position, such as in a design rationale.
