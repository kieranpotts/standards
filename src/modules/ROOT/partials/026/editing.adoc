= Editing

Many of the rules in this standard are easier to apply while editing than while drafting. Write the first draft for content, then revise it against this standard.

After drafting, re-read the text as the reader will meet it. Ask what makes it read as generic, padded, or evasive, and revise anything that stands out.

Prefer an edit that adds a concrete detail over one that only deletes a flagged word. Replacing "optimized performance" with the measured speed-up fixes the sentence. Deleting "optimized" leaves a claim with nothing behind it.
