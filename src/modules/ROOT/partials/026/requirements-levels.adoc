= Requirements levels

Use the Internet Engineering Task Force (IETF) RFC 2119 requirement keywords — MUST, MUST NOT, REQUIRED, SHOULD, SHOULD NOT, RECOMMENDED, MAY, and OPTIONAL — in body prose to express an obligation, a prohibition, or an option.

Render each keyword in capitals. {link-ietf-rfc8174}[IETF RFC 8174], which together with RFC 2119 forms BCP 14, clarifies that a keyword carries its special meaning only when written in capitals. Do not write a keyword in lowercase or mixed case, eg. "should not" or "Must".

Prefer this over using softer everyday phrasing such as "should probably" or "it's a good idea to".

A document that relies on these keywords MUST state, once, near its start, that they carry the meanings defined in {link-ietf-rfc2119}[IETF RFC 2119]. A collection of documents MAY instead make the statement once, on the collection's front page. An example follows.

[quote]
____
The keywords MUST, MUST NOT, REQUIRED, SHOULD, SHOULD NOT, RECOMMENDED, MAY, and OPTIONAL, written in their full uppercase forms, are to be interpreted as described in IETF RFC 2119.
____
