= Code blocks

Every code block MUST specify its language on the `[source,<language>]` line (`bash`, `sh`, `json`, and so on) so syntax highlighting renders correctly; see the repository's style guide for the full rule. Indent code with spaces, not tabs, so the block renders consistently regardless of the reader's editor settings.

Keep a code example narrow enough to read without horizontal scrolling in a typical rendered column — wrap or truncate a long line rather than letting it run off the edge of the page.
