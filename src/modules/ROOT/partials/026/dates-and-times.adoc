= Dates and times

Write dates in ISO 8601 format (`2026-07-02`) in technical documentation, since it sorts correctly as a string and is unambiguous across locales. Avoid the `MM/DD/YYYY` and `DD/MM/YYYY` formats entirely, as both are ambiguous without knowing the writer's locale.

Write a time of day in 24-hour format (`14:30`), for the same reason ISO dates are required: it sorts correctly and is unambiguous across locales, unlike `2:30pm` or `2.30pm`. Where a document must show 12-hour format for a non-technical audience, write it as `2:30 pm`, with a space before the lowercase `am`/`pm` and no periods.
