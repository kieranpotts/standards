= Figures, tables, and examples

// TODO: Anything more to say about figures, tables, and examples?

Do not refer to a figure, table, or code example by its position on the page — "the table above", "the diagram below". "The following example" and "as follows" are fine where the example comes directly after the sentence, because nothing can reflow between them. Position is not stable across formats. A reflowable or narrow-viewport rendering can move a figure to a different position relative to the text that cites it.

Instead, refer to figures, tables, and examples by explicit cross-references. Use incrementing numbers — "Figure 1" — or unique figure captions for this purpose.
