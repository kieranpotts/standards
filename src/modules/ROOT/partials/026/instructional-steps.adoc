= Instructional steps

Sequence a procedure chronologically, not spatially. Prefer "next, select Save to continue" over "click the Save button below". A spatial reference such as "below", "above", or "on the left" assumes a fixed visual layout that a may not be applicable to all UI views (eg. screenreaders, mobile views). A step written as a position in a sequence ("next", "then", "finally") holds regardless of how the interface is rendered or navigated.

When a step describes an action in a user interface, prefer a device-agnostic action verb over a device-specific one. Example: "select" or "choose", over "click", "tap", or "press"; "view" over "see". A device-specific verb such as "click" assumes one mode of human-computer interaction, in this case mouse interaction, not keyboard, touch, and assistive-technology interaction. This does not apply to "see" in a cross-reference, eg. "See TS-25".
