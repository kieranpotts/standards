= Dangling participles

A *dangling participle* is an introductory participial phrase whose implied subject does not match the sentence's actual subject. The ❌ example wrongly implies that the request did the configuring.

----
✅ Having configured the server, you send the request.
✅ After you configure the server, the request succeeds.
❌ Having configured the server, the request succeeds.
----
