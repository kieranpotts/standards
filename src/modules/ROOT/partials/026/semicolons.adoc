= Semicolons

Prefer two separate sentences over a semicolon joining two independent clauses. A semicolon signals a closer relationship between the clauses than a period does, but that relationship is rarely load-bearing enough to justify the harder read.

Reserve the semicolon for joining short items in a list written inline, or for the exception described in Sentences and paragraphs.

----
✅ A write invalidates the cache. This keeps reads consistent with the latest data.
❌ A write invalidates the cache; this keeps reads consistent with the latest data.
----
