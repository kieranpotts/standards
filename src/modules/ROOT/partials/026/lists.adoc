= Lists

Use a numbered list when the order of items matters, such as steps in a procedure. Use a bulleted list when the order does not matter.

Keep list items grammatically parallel. If the first item starts with an imperative verb, every subsequent item SHOULD. Do not mix sentence fragments with full sentences in the same list.

Punctuate list items as sentences (capitalized, ending in a period) when any item is a full sentence. Terminate the lead-in sentence with a period, not a colon or dash.

----
Before deploying, complete the following checks.

* Run the full test suite and confirm it passes.
* Review the changelog for breaking changes.
* Notify the on-call engineer of the deployment window.
----

Sometimes items in a list will not form proper sentences, for example where the list items name things in a collection. In that case, capitalize the first word of each item and omit the terminal period.

----
The following browsers are supported.

* Chrome
* Firefox
* Safari
* IE 10+
* Edge
----

Avoid nesting lists more than two levels deep. Deeply nested lists are hard to scan. Restructure into subsections instead.

----
✅ * Supported runtimes
✅   * Node.js 20 and later
❌ * Supported runtimes
❌   * Node.js
❌     * Versions 20 and later
----
