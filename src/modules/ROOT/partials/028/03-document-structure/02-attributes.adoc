= Attributes

{link-asciidoctor-attributes}[Attributes] are a way of creating a variable whose value can be used throughout the document. Using attributes is encouraged as it increases readability and makes it easy to change shared content in one place.

An attribute is declared in an attribute entry, which has the following form.

[source,asciidoc]
----
:name-of-attribute: value
----

Attributes that apply to a whole document SHOULD be declared in the document header, in a contiguous block directly beneath the title. Within the block, attribute entries are delimited by single newlines. Some built-in attributes, such as `toc` and `experimental`, only take effect when they are set in the header.

An attribute MAY instead be declared in the document body, where it takes effect from that line onward. This is how a set of attributes is shared between several files. The attribute entries are kept in a file of their own, and that file is included above the first line that references them. Attribute entries in the body MUST still be kept together in one contiguous block, and each attribute MUST be declared before its first use.

To reference an attribute, use curly braces `{}` around the attribute name.

[source,asciidoc]
----
Lorem ipsum {name-of-attribute} ...
----

A literal `{...}` that is not an attribute reference needs to be escaped when it is written in prose. See <<escaping,Escaping>>.
