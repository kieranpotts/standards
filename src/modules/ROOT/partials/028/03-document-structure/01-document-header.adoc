= Document header

The document header is the block of lines at the very top of a document. It holds the document title, optionally followed by author and revision lines, and then any document attributes. The header MUST NOT contain blank lines, because the first blank line in the document terminates it.

[source,asciidoc]
----
= The page header
:toc: macro
:experimental:

The first paragraph of the document body.
----

The document title resembles a level-0 section title. It is written as a single equals sign (`=`) followed by at least one space, then the text of the title. It follows the same capitalization rule as section titles. See <<sections,Sections>>.

A document MUST NOT have more than one document title. The one exception is a file that is composed into a larger document by an include directive with a `leveloffset`. Such a file starts with its own `=` title, which the offset demotes to a section title in the composed document. See <<include-directive,Include directive>>.
