= Table of contents (TOC)

Asciidoctor can automatically generate a table of contents from the sections and subsections within the document.

The easiest way to add a TOC is to set the `toc` attribute in the document header.

[source,asciidoc]
----
= The page header
:toc:
----

The TOC will be automatically placed within the rendered document. To control the position of the TOC, set the attribute's value to `macro`, and write the `toc::[]` block macro where the TOC is to appear.

[source,asciidoc]
----
= The page header
:toc: macro

Introductory text…

toc::[]
----

Other attributes, such as `toc-title` and `toclevels`, can be used to configure the TOC.

[source,asciidoc]
----
:toc: macro
:toclevels: 2
:toc-title: Contents
----

The `toc` attribute has no effect on a site built with Antora, where the UI generates each page's TOC. See <<antora,Antora>>.
