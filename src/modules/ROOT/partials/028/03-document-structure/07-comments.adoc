= Comments

Use comments to leave information for other maintainers of the documentation. Comments are not included in the rendered output.

Single-line comment notation is preferred.

[source,asciidoc]
----
// Needs revision as a new release will change the parameter.
----

If you want to comment a block, put the block between two lines of four slashes (`////`).

[source,asciidoc]
----
////
Needs revision as a new release will change the parameter.

Maybe complex to do but let's see.
////
----
