= Attributes

https://docs.asciidoctor.org/asciidoc/latest/attributes/document-attributes/[Attributes] are a way of creating a variable whose value can be used throughout the document. Using attributes is encouraged as it increases readability and makes it easy to change shared content in one place.

All attributes MUST be defined in a contiguous block in the document header. The document header is terminated by the first blank line in the document. Within the header block, attributes are delimited by single newlines, and each has the following form.

```
:name-of-attribute: value
```

To reference an attribute in the document body, use curly braces `{}` around the attribute name.

```
Lorem ipsum {name-of-an-attribute} ...
```

A literal `{...}` that isn't an attribute reference — a URI template variable, a shell `$\{var}` expansion, a JSDoc `\{type}` annotation, or similar — is safe to write as-is inside a delimited block (`` ---- ``), where AsciiDoc does not perform attribute substitution. But the same text written inline in prose, in a table cell, or in a list item MUST have its opening brace escaped as `\{...}`. The escape renders identically and keeps the real syntax intact.
