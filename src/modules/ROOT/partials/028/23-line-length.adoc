= Line length and wrapping

Lines SHOULD NOT exceed 120 characters. Content longer than this SHOULD be "soft
wrapped" — that is, continued on the next line without any special line-break
syntax. Adjacent lines within an AsciiDoc paragraph are combined into a single
line in the rendered output, so soft wrapping does not affect how the document
renders.

See <<preserving-line-breaks,Preserving line breaks>> for how to
force an actual line break where one is needed.

The purpose of this constraint is to ensure that files render identically in
every editor, regardless of the editor's own line-wrapping width or settings.

A soft wrap MUST NOT be inserted within an inline formatting unit, such as bold
or italic text, so as to preserve the formatting markers (eg. `*` or `_`)
alongside the text they format. Let a line run longer than 120 characters
rather than breaking one of these spans.

The same applies to link macros, which MUST NOT be broken across lines. Where
keeping a link intact takes a line past 120 characters, the link wins.
