= Native syntax

Asciidoctor supports a subset of Markdown syntax as an alternative to some standard AsciiDoc syntax. Native AsciiDoc syntax SHOULD be used, not Markdown styles that happen to be supported by Asciidoctor. The Markdown-style forms cover only part of the language, and some of them behave differently from their native equivalents.

[cols="1,1,1"]
|===
| Construct | Markdown-style form | Native AsciiDoc form

| Section heading
| `+# Title+`
| `+= Title+`

| Code block
| Three backticks
| `+[source]+` with `+----+` delimiters

| List item
| `+- item+`
| `+* item+`

| Quotation
| `+> text+`
| `+[quote]+` with `+____+` delimiters

| Horizontal rule
| `+---+`
| `+'''+`
|===
