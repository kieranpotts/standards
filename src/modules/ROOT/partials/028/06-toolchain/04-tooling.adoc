= Tooling

Asciidoctor reports problems such as a broken include, a cross-reference to a missing anchor, or an out-of-sequence section level as warnings, and still produces output. A documentation build SHOULD be configured to fail on warnings, so these problems are not published. For the Asciidoctor command line, use the `--failure-level=WARN` option. For Antora, use the `--log-failure-level=warn` option.

A link checker SHOULD be run as part of continuous integration to detect broken external links, which neither Asciidoctor nor Antora checks.

It is RECOMMENDED that code editors have the following settings.

* Long lines are soft wrapped for display (eg. `"editor.wordWrap": "on"` in VS Code).
* Trailing whitespace is highlighted.
* Files end with a single newline character.
* Indentation uses spaces, not tabs.
