= PDF output

When a document is converted to PDF, a block can be split across two pages. Use the `%unbreakable` option to prevent page breaks in a block. A block that would otherwise be split is moved to the top of the next page.

The option is written as part of the first entry in the block's attribute list, directly after the block's style.

[source,asciidoc]
----
[verse%unbreakable, William Blake, Songs of Experience]
____
Tiger, tiger, burning bright
In the forests of the night,
What immortal hand or eye
Could frame thy fearful symmetry?
____
----

The option MUST NOT be written as an entry of its own ahead of the style. In the following example, `%unbreakable` takes the place of the style, so `verse` is read as the attribution, and the block is rendered as an ordinary quotation.

[source,asciidoc]
----
[%unbreakable, verse, William Blake, Songs of Experience]
____
Tiger, tiger, burning bright
____
----

To keep several consecutive blocks together on one page, wrap them in an open block and apply the option to that.

[source,asciidoc]
------
[%unbreakable]
--
.Example request
[source,bash]
----
curl https://api.example.com/health
----

The command returns the status of each dependency.
