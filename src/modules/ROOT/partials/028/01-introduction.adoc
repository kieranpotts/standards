AsciiDoc is RECOMMENDED for technical documentation. It is preferred over other lightweight human-editable text markup languages such as Markdown, because AsciiDoc is specifically designed for technical writing, it supports embedded diagrams and lots of other valuable features, and it has great tooling for publishing content to different formats such as PDFs and ebooks. It also benefits from a single reference implementation, {link-asciidoctor}[AsciiDoctor], which means AsciiDoc does not have the same compatibility issues between rendering engines as Markdown has.

This technical standard offers tips and best practices for writing AsciiDoc, and for using tools such as {link-asciidoctor}[AsciiDoctor] and {link-antora}[Antora] to process AsciiDoc files.

For a complete language reference, see the {link-asciidoctor-docs}[Asciidoctor Documentation]. The AsciiDoctor website also has a useful {link-asciidoctor-syntax-quick-reference}[AsciiDoc Syntax Quick Reference] guide.
