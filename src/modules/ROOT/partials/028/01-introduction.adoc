AsciiDoc is RECOMMENDED for technical documentation. It is preferred over other lightweight human-editable text markup languages such as Markdown, because AsciiDoc is specifically designed for technical writing, it has built-in support for cross-references, admonitions, modular files, and conditional content, and it has mature tooling for publishing content to different formats such as HTML, PDF, and EPUB. It also benefits from a single reference implementation, {link-asciidoctor}[Asciidoctor], which means AsciiDoc does not have the same compatibility issues between rendering engines as Markdown has.

This technical standard defines conventions for writing AsciiDoc, and for using {link-asciidoctor}[Asciidoctor] and {link-antora}[Antora] to process AsciiDoc files. It covers markup only. For what to document and where to keep it, see xref:025.adoc[*TS-25: Technical Documentation*]. For prose style, see xref:026.adoc[*TS-26: Technical Writing Style Guide*]. For short, simple documents such as `README` files, see xref:027.adoc[*TS-27: Markdown*].

For a complete language reference, see the {link-asciidoctor-docs}[Asciidoctor Documentation]. The Asciidoctor website also has a useful {link-asciidoctor-syntax-quick-reference}[AsciiDoc Syntax Quick Reference] guide.
