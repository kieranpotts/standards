[#escaping]
= Escaping

Text that would otherwise be interpreted as AsciiDoc markup is written literally by prefixing it with a backslash (`\`).

[source,asciidoc]
----
\*This text is not bold.*

\https://www.example.com/
----

Escaping SHOULD be used only where it is needed. Where a whole phrase is to be output exactly as it is typed, enclosing it in plus signs is clearer than escaping each construct within it. See <<text-formatting,Text formatting>>.

== Curly braces

A literal `{...}` that isn't an attribute reference — a URI template variable, a shell `$\{var}` expansion, a JSDoc `\{type}` annotation, or similar — is safe to write as-is inside a listing or literal block, where AsciiDoc does not perform attribute substitution. This does not hold for the other kinds of delimited block, such as example and quote blocks, whose content is processed as normal. The same text written inline in prose, in a table cell, or in a list item MUST have its opening brace escaped as `\{...}`. The escape renders identically and keeps the real syntax intact.

== Directives

Include directives and conditional directives are processed everywhere in a document, including inside listing and literal blocks. To show one literally, prefix it with a backslash.

[source,asciidoc]
----
\include::partial$example.adoc[]
----
