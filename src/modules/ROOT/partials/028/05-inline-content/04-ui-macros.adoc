= UI macros

The UI macros style snippets of inline text to represent parts of a user interface: keys on a keyboard, buttons, and menu selections.

[IMPORTANT]
======
You MUST set the `:experimental:` attribute to enable the UI macros.
======

== Keyboard shortcuts

The syntax for keyboard shortcuts is: `+kbd:[key(+key)*]+`.

[source,asciidoc]
----
kbd:[F11]
kbd:[Ctrl+T]
kbd:[Ctrl+Shift+N]
----

== Buttons

The syntax for UI button text is: `+btn:[text]+`.

[source,asciidoc]
----
btn:[OK]
btn:[Open]
btn:[Show disabled apps]
----

== Menu selections

The syntax for menu selections is: `+menu:start[next > next > *]+`.

[source,asciidoc]
----
Go to menu:Settings[Admin > Apps] and click on btn:[Show disabled apps].
----
