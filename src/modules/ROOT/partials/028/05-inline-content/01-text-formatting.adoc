[#text-formatting]
= Text formatting

Bold text is enclosed in asterisks, italic text in underscores, and monospace text in backticks.

[source,asciidoc]
----
*bold text*
_italic text_
`monospace text`
*_bold and italic text_*
----

These single marks are _constrained_. They are only recognized at the boundaries of a word or phrase. Where formatting must begin or end inside a word, double the marks to make them _unconstrained_. The doubled form SHOULD be used only where the single form does not work.

[source,asciidoc]
----
**C**reate, **R**ead, **U**pdate, and **D**elete
----

Text inside backticks is still processed. Attribute references are replaced, and macros such as links are converted. To write monospace text that is output exactly as it is typed, also enclose it in plus signs, inside the backticks.

[source,asciidoc]
----
`+{name}+` and `+https://example.com/+`
----

For guidance on when to use bold, italic, and monospace text, see xref:026.adoc[*TS-26: Technical Writing Style Guide*].
