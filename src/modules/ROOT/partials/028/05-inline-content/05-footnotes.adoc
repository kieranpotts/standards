= Footnotes

A footnote is written with the `footnote` macro, placed directly after the text it annotates, with no space before it. The text of the footnote is written inside the macro's square brackets.

[source,asciidoc]
----
The request is retried three times.footnote:[The retry count is configurable.]
----

Asciidoctor numbers the footnotes and collects them at the end of the document. To refer to the same footnote from more than one place, give it an ID where it is first written, then reference the ID with empty brackets.

[source,asciidoc]
----
The first statement.footnote:retries[The retry count is configurable.]

A later statement.footnote:retries[]
----

For guidance on when to use footnotes, see xref:026.adoc[*TS-26: Technical Writing Style Guide*].
