= Include directive

The https://asciidoctor.org/docs/user-manual/#include-directive[include directive] is used to include the content from another file in the current document. It helps to keep AsciiDoc files small and modular. Documentation sites and technical books are thus _composed_ from lots of files being included in one main file. Includes directives also allow reusing of content — such as code examples — in multiple places.

An include directive is written in the following form.

```
\include::<path>/file[<attrlist>]
```

The `attrlist` is OPTIONAL and can contain one or more comma-separated attributes that modify the behavior of the include directive. For exampke, `leveloffset=+1` will adjust the section levels of the included file. Heading level 1 (`=`) will become level 2 (`==`), level 2 will become level 3, and so on.

https://antora.org/[Antora], a documentation generation tool, imposes some additional constraints on how files can be included in AsciiDoc source files.
