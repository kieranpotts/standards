= Literal blocks

Literal blocks display the text you write exactly as you enter it. Literal text is treated as pre-formatted text.

[source,asciidoc]
----
....
Checking system health.
- file permissions are ok.
....
----

Use a literal block for preformatted text that is not source code, such as the output of a command or a directory tree. Use a code block for anything written in a programming, markup, or configuration language.

For literal text within a line of prose, see <<text-formatting,Text formatting>>.
