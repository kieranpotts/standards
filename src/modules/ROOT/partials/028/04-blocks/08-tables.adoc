= Tables

Tables are delimited by `|===` and made up of cells. Cells are separated by a vertical bar `|`.

[source,asciidoc]
----
[cols="1,2"]
|===
| Header of column 1      | Header of column 2

| Cell in column 1, row 1 | long Cell in column 2, row 1
| Cell in column 1, row 2 | long Cell in column 2, row 2
| Cell in column 1, row 3 | long Cell in column 2, row 3
|===
----

The cells of a row can also be written underneath each other, one cell per line, with a blank line between rows. This form SHOULD be used for any table whose cells hold more than a few words. It keeps each source line short, and a change to one cell shows up as a change to one line.

[source,asciidoc]
----
[cols="1,4"]
|===
| Directory
| Description

| `data/<user>/files_encryption`
| Users' private keys and all other keys necessary to decrypt the users' files.

| `data/files_encryption`
| Private keys and all other keys necessary to decrypt the files stored on a system wide external storage.
|===
----

The following rules apply to all tables.

* A table SHOULD have a header row. The first row is treated as the header where all of its cells are written on the first line and that line is followed by a blank line, as in both examples above. The `%header` option makes the same thing explicit, as in `[%header,cols="1,2"]`.

* The number and relative widths of columns SHOULD be set by the `cols` attribute, using proportional values such as `cols="1,2"`, rather than percentages. Fixing the width of the table as a whole SHOULD be avoided, so the table can adapt to the output format.

* Each cell MUST sit on a single source line, however long. See <<line-length,Line length and wrapping>>.

* A cell that needs block content, such as a list or more than one paragraph, MUST be marked with the `a` style, written directly before the cell's vertical bar (`a|`). Otherwise the cell's content is treated as a single paragraph.

* A literal vertical bar inside a cell MUST be escaped with a backslash (`\|`).

* A table that needs a caption SHOULD be given a block title. See <<block-titles,Block titles>>.
