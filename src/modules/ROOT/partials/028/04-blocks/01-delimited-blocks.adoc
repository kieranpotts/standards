[#delimited-blocks]
= Delimited blocks

A delimited block is a run of lines enclosed between a pair of delimiter lines. The delimiter determines how the content is treated.

[cols="1,1,3"]
|===
| Block | Delimiter | Content

| Listing
| `+----+`
| Source code and other verbatim text.

| Literal
| `+....+`
| Preformatted text, such as terminal output.

| Example
| `+====+`
| Any block content. Also the container for a complex admonition.

| Sidebar
| `+****+`
| Any block content, set aside from the main flow.

| Quote
| `+____+`
| A quotation or a verse.

| Open
| `+--+`
| Any block content. A generic container with no styling of its own.

| Passthrough
| `pass:[++++]`
| Raw content that is passed to the output unprocessed.

| Comment
| `+////+`
| Content that is omitted from the output.
|===

The opening and closing delimiters of a block MUST be the same length. The minimum length is four characters, except for the open block, whose delimiter is always two hyphens.

A longer delimiter is used to nest a block inside another block of the same type. The inner block's delimiters are a different length from the outer block's, which is how the processor tells them apart.

[source,asciidoc]
------
====
The outer example block.

======
The inner example block.
======
====
------

A block is configured by the lines directly above its opening delimiter: an attribute list in square brackets, such as `[source,bash]` or `[NOTE]`, and optionally a block title. There MUST NOT be a blank line between these lines and the block they apply to.

A blank line SHOULD be placed before and after each block.
