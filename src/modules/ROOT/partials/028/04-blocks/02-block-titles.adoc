[#block-titles]
= Block titles

You can assign a title to any paragraph, list, delimited block, or block macro. In most cases, the title is displayed immediately above the content. If the content is a figure or image, the title is displayed below the content.

A block title is defined on a line immediately above the element. The line MUST begin with a dot (`.`) and be followed immediately (no space) by the title text.

[source,asciidoc]
----
.Title for this paragraph
Text or lists or...
----

Block titles follow the same capitalization rule as section titles. See <<sections,Sections>>.
