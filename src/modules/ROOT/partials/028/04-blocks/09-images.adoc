= Images

Image files are embedded using either the `image:` (inline) or `image::` (block-level) syntax.

[source,asciidoc]
----
image:<path>/image_name[Alternative image text, <options>]
----

All images MUST have alternative text. The alternative text SHOULD concisely describe the content of the image. Where the alternative text includes any commas, it MUST be wrapped in double quotes. Otherwise, the text after the first comma is read as the next option rather than as part of the alternative text.

The `<options>` part is optional. This is used to do things like adjust the size of the rendered image, eg. `width=40%`.

The inline image syntax is useful for embedding small icons within text. Block-level images MUST be used for large graphics that need to be accompanied by a caption. The caption is written as a block title.

[source,asciidoc]
----
.Request flow through the gateway
image::<path>/request-flow.svg["Sequence diagram of a request passing through the gateway, the cache, and the origin", width=80%]
----

Block-level images are aligned to the left by default, but you can adjust this on a case-by-case basis using the `align="center|left|right"` option.

In a site built with Antora, the image target is a resource ID rather than a file system path. See <<antora,Antora>>.
