= Keyboard shortcuts and UI button text

You can style snippets of inline text like buttons. This convention is typically used to represent computer
keyboard input.

The syntax for UI button text is: `btn:[text]`.

The syntax for keyboard shortcuts is: `kbd:[key(+key)*]`.

Examples:

```
kbd:[F11]
kbd:[Ctrl+T]
kbd:[Ctrl+Shift+N]
kbd:[Show disabled apps]

btn:[OK]
btn:[Open]
```
