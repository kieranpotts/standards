= Frontmatter

Frontmatter is a block of metadata at the very top of a Markdown file, written in YAML between two lines of three hyphens (`---`). It is used by static site generators and other tools to carry information such as a page's title, date, and tags.

----
---
title: Getting started
tags: [guide, onboarding]
---

# Getting started
----

Frontmatter is not part of CommonMark or GFM. A renderer that does not support it displays the block as a horizontal rule followed by text. Frontmatter SHOULD therefore be used only in files that are consumed by a tool that requires it.

Where it is used, the opening `---` MUST be the first line of the file, and the YAML between the delimiters SHOULD follow xref:030.adoc[*TS-30: YAML*].
