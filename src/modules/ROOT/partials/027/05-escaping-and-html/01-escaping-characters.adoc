= Escaping characters

A literal character that would otherwise be interpreted as Markdown formatting MUST be escaped by prefixing it with a backslash (`\`).

----
\* This is not a list item.
----

The following characters have a meaning in Markdown syntax, and are the ones most likely to need escaping. CommonMark allows any ASCII punctuation character to be escaped.

----
\ ` * _ { } [ ] < > ( ) # + - . ! |
----

Escaping MUST be used only where necessary. A character from this list that would not be interpreted as formatting in its position, such as a hyphen in the middle of a sentence, MUST NOT be escaped. Prefer to restructure content to avoid ambiguity, for example by adding blank lines around elements, rather than escaping many characters.
