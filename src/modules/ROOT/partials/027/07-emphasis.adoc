= Emphasis

Use underscores (`_`) for italics and double asterisks (`**`) for bold.

----
_italic text_
**bold text**
**_bold and italic text_**
----

Do not use the single asterisk (`*`) syntax to demarcate italic text. Using different markup characters for italics and bold text helps to keep both visually distinct.

However, underscores in the middle of a word are not interpreted as emphasis by some processors. Where emphasis must fall inside a word, use a single asterisk (`*text*`) instead, which is reliable in all positions.

For GFM, strikethrough is written using two tildes (`~~`).

----
~~struck-through text~~
----

Emphasis SHOULD be applied to words or short phrases, not to entire paragraphs.

Do not nest emphasis unnecessarily.
