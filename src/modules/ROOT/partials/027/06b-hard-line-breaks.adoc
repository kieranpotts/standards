= Hard line breaks

To insert a hard line break (`<br>`) within a paragraph, at the end of the line add a space following by a single backslash chaarcter (`\`), then continue the paragraph text on a new line.

The alternative syntax for hard line breaks is two end-of-line spaces. This form SHOULD NOT be used, because the syntax relies solely on invisible whitespace characters, and because auto-formatters may be configured to strip trailing spaces on the end of lines in code and text documents. Indeed, it is RECOMMENDED to configure editors to highlight trailing whitespace, or to remove it automatically on file save, to avoid accidental hard line breaks being inserted into paragraphs.

Hard line breaks SHOULD be used sparingly, and only where a break is semantically required, for example in a postal address or a verse.

See also <<line-length,line length and wrapping>> for guidelines on use of soft line wraps.
