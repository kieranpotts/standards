= Placeholders

The general convention across these standards is to write placeholder text in angle brackets (`<placeholder>`), as specified in xref:026.adoc[*TS-26: Technical Writing Style Guide*]. Markdown is a partial exception. Where the placeholder sits inside a code span or a fenced code block, angle brackets SHOULD be used as normal, because nothing inside code snippets is parsed as HTML.

----
git clone git@<hostname>:<group>/<project>.git
----

Everywhere else — in bare prose, headings, table cells — placeholder text MUST be written in square brackets (`[placeholder]`). Markdown permits raw HTML inline, so outside code formatting a `<placeholder>` would be interpreted as an unknown HTML element by parsers, causing unexpected rendering.

Escaping the angle brackets with backslashes also prevents this, but square brackets are easier to read in the source and cannot be broken by a missed escape.
