[#paragraphs-and-line-breaks]
= Paragraphs and line breaks

A paragraph is a run of text separated from the surrounding content by a blank line. How it is wrapped across source lines is covered in <<line-length,Line length and wrapping>>.

Paragraphs SHOULD NOT be indented with spaces or tabs. Leading indentation of four or more spaces may be interpreted as
a code block.

To insert a hard line break (`<br>`) within a paragraph, end a line with two or more spaces, or use a backslash (`\`) at the end of the line. The backslash form is RECOMMENDED, for clarity and because an auto-formatter that strips end-of-line whitespace will silently remove the two-space form. A hard line break changes the rendered output, unlike a soft wrap in the source.

Hard line breaks SHOULD be used sparingly, and only where a break is semantically required — a postal address, a verse, a short lead-in term set above the text it introduces. Prefer separate paragraphs or lists.

[NOTE]
======
Trailing whitespace is invisible in most editors. Configure your editor to
highlight trailing whitespace, or use a linter, to avoid accidental hard line
breaks.
======
