= Code

== Inline code

Inline code is written with single backticks.

----
Use the `console.log()` function.
----

Code that itself contains backticks may be enclosed in double backticks, with a space between the backticks and the content for clarity.

----
Use the `` echo `date` `` command.
----

== Code blocks

Fenced code blocks are written using three backticks on the lines before and after the block. Fenced code blocks are RECOMMENDED over indented code blocks (four-space indentation), as they are easier to read and edit in source.

....
```json
{
  "name": "example"
}
```
....

A language identifier SHOULD be specified immediately after the opening fence, to enable syntax highlighting where the renderer supports it. Use `plaintext` for examples that do not belong to a specific language, which disables syntax highlighting in renderings.

Where a code block itself contains a fenced code block, as in documentation about Markdown, the outer fence MUST be longer than the inner one. Use four backticks for the outer fence.

....
````markdown
```json
{
  "name": "example"
}
```
````
....

For conventions on the content of code blocks — CLI prompts, placeholders, and multi-line shell commands — see xref:026.adoc[*TS-26: Technical Writing Style Guide*]. Placeholders outside code need special treatment in Markdown. See <<placeholders,Placeholders>>.
