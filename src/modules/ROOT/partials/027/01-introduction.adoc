Markdown is a general-purpose, lightweight, human-editable plain text markup language. It is widely used for simple documentation such as `README` files, contribution guides, changelogs, pull request descriptions, and code comments. It is supported by many source code hosting platforms, issue trackers, and chat tools.

Markdown's design goal is to be readable as-is, without the formatting tags or instructions of a richer markup language, while still allowing the text to be converted to structured formats such as HTML.

Markdown is well-suited to short, relatively simple documents. It is a good choice for the following use cases.

* `README` files and other repository meta-documents.
* Changelogs, pull request descriptions, and issue comments.
* Code comments and API documentation that is co-located with source code.
* Chat and messaging platforms that support Markdown input.

However, when you need advanced formatting options such as auto-generated tables of contents, cross-references, complex tables, admonitions, conditional rendering, and modular files that can be included in others, AsciiDoc is RECOMMENDED over Markdown. AsciiDoc offers a richer range of formatting options, and the language and build tools are designed specifically for the use case of structured technical documentation.
