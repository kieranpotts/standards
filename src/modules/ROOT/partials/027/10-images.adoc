= Images

Images are written with an exclamation mark, followed by alternative text in
square brackets, and the image path or URL in parentheses. An optional title may
follow in double quotes.

```
![Alt text](/assets/images/diagram.png "System diagram")
```

All images MUST have alternative text. The alternative text SHOULD concisely
describe the content of the image; see
xref:026.adoc[*TS-26: Technical writing style guide*] for guidance.

To link an image, wrap the image syntax in a link:

```
[![Alt text](/assets/images/logo.png)](https://www.example.com)
```

Markdown does not provide a standard way to set image dimensions. Where sizing
or alignment is required, use an HTML `<img>` tag with explicit `width` and
`height` attributes.
