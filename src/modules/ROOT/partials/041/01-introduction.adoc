This technical standard covers best practices for working with React, a popular JavaScript library used for composing graphical user interfaces from reusable components.

The guidance here assumes React 19 or later, authored as function components with hooks, in TypeScript. The guidance is written for React on the web, but the component, state, and filesystem conventions apply to React's other render targets too.

See also xref:036.adoc[*TS-36: ECMAScript (JavaScript/TypeScript)*] and xref:018.adoc[*TS-18: Web GUIs*]. For building interfaces with Vue instead, see xref:042.adoc[*TS-42: Vue*].
