= Importing React

Since React 17's new JSX transform, a module that uses JSX no longer needs `React` in scope. The compiler imports the JSX runtime itself. Hooks and other APIs still need to be imported from the `react` package individually, by name.

[source,tsx]
----
/* Before React 17 */
import React, { useState } from "react"

/* From React 17 */
import { useState } from "react"

const [things, setThings] = useState([])
----

It is RECOMMENDED instead to import the `react` package as a namespace (`import * as React`), and so to reach every React API through the `React` identifier. A namespace import makes React-specific code stand out at the point of use, eg. `React.useState`, `React.Suspense`, `React.ComponentProps`). It avoids collisions between React's export names and a project's own identifiers. Plus, a module's import line does not have to change each time it adopts another hook. The tradeoff is slightly more verbose (but clearer) code.

[source,tsx]
----
import * as React from "react"

const [things, setThings] = React.useState([])
----
