= References

* Smudford, T (2024). https://www.trysmudford.com/blog/hyper-responsive-web-components/[_Hyper-Responsive Web Components_].
  — The source for the portable-embeddable-widget motivation and the
  script-injection/iframe/Shadow-DOM comparison in <<When to use web
  components>> and <<Choosing an encapsulation strategy>>, the custom-element
  build pattern in <<Building a custom element>>, and the `:root` `rem` leak
  in <<Shadow DOM>>.

* Rupert, D (2024). https://daverupert.com/2024/10/super-web-components-sunshine/[_Super Web Components, Sunshine!_].
  — The source for the "good parts" catalog in <<When to use web
  components>> and the SSR/Declarative-Shadow-DOM, page-routing, and
  cross-root-ARIA limitations in <<Limitations>> and <<Shadow DOM>>.

* Keith, J (2024). https://adactio.com/journal/20618[_HTML Web Components_].
  — The source for the HTML-vs-JavaScript web component distinction, the
  `super-slider` and `icon-list` examples, and the augmentation-over-replacement
  argument in <<HTML web components vs. JavaScript web components>> and
  <<Shadow DOM>>.

* WHATWG. https://dom.spec.whatwg.org/[_DOM Standard_] and
  https://fetch.spec.whatwg.org/[_Fetch Standard_]. — The source for the
  event-propagation model, `fetch`, and CORS mechanics in
  <<DOM events and HTTP requests>>.
