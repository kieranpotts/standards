  — The source for the portable-embeddable-widget motivation and the script-injection/iframe/Shadow-DOM comparison

* Rupert, D (2024). https://daverupert.com/2024/10/super-web-components-sunshine/[_Super Web Components, Sunshine!_].

  SSR/Declarative-Shadow-DOM, page-routing, and cross-root-ARIA limitations in <<Limitations>> and <<shadow-dom,Shadow DOM>>.

  <<shadow-dom,Shadow DOM>>.
