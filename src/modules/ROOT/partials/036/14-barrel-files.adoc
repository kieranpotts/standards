= Barrel files

A barrel file is a TypeScript/JavaScript design pattern used to simplify and centralize exports from a module or
directory.

Instead of importing individual components or utilities from multiple files, you create a single file – often named
`index.ts` – that re-exports everything from those files. This makes imports cleaner and easier to manage.

Example:

[source,plaintext]
----
/utils
  ├── formatDate.ts
  ├── parseUrl.ts
  └── index.ts
----

Each utility file exports a function:

[source,typescript]
----
// formatDate.ts
export function formatDate(date: Date): string { ... }

// parseUrl.ts
export function parseUrl(url: string): object { ... }
----

The barrel file (`index.ts`) re-exports these exports:

[source,typescript]
----
export * from './formatDate';
export * from './parseUrl';
----

Now, instead of importing like this:

[source,typescript]
----
import { formatDate } from './utils/formatDate';
import { parseUrl } from './utils/parseUrl';
----

You can do this:

[source,typescript]
----
import { formatDate, parseUrl } from './utils';
----
