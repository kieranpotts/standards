= File extensions

`.yaml` is the officially recommended extension, and has been since 2006.
`.yml` persists from the era of 8.3 (DOS-style) filename limits and is still
the dominant convention in some ecosystems (Ruby/Rails, Docker Compose).

New projects SHOULD use `.yaml`. An existing project SHOULD stay consistent
with whichever extension it already uses throughout — do not mix `.yaml` and
`.yml` within the same project. Where a tool mandates a specific extension
(eg. a framework that only auto-discovers `config.yml`), follow the tool's
requirement.
