= Mitigation strategies

The final stage of the threat modeling process is to decide on mitigation
strategies for each identified threat. The rationale for the chosen
countermeasures – or the reasons why no mitigation will be done – SHOULD be
recorded against each threat.

Examples of countermeasures against common threats include:

* Two-factor authentication.
* Role-based access controls.
* Encryption of sensitive data at rest.
* Encrypted transport protocols.
* Message signatures.
* Logging, monitoring, and alerts.
* Rate limiting.
* Reducing data retention periods.
* Code review.
* Log rotation.
* Penetration testing.
* Dependency updates.
* Dependency version pinning.
* Scheduled security scans.
