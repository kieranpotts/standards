= State

State setters in React SHOULD NOT directly pass new state values, but SHOULD
instead use the callback API, which receives the current state value as its
argument and which is expected to return the new state value. Although this is
more verbose, it is best practice because it ensures that the new state value is
based on the most recent state value.

[source,jsx]
----
export default function App() {
  const [count, setCount] = React.useState(0)

  /* No: */
  function add() {
    setCount(count++)
  }

  /* Yes: */
  function subtract() {
    setCount(prevCount => prevCount - 1)
  }

  return (
    <div className="counter">
      <button className="counter--minus" onClick={subtract}>–</button>
      <div className="counter--count">
        <h1>{count}</h1>
      </div>
      <button className="counter--plus" onClick={add}>+</button>
    </div>
  )
}
----

****
In the above example, by convention, the name of the callback's argument SHOULD
be `prev` followed by the name of the state variable.
****
