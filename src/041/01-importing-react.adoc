= Importing React

From React v17, the explicit import of `React` is no longer required.

[source,jsx]
----
import React from "react"
----

Hooks and other utilities can be imported from the `react` package individually.

[source,jsx]
----
/* React ≤ v17 */
import React, { useState } from "react"

/* React ≥ v18 */
import { useState } from "react"

/* Usage: */
const [things, setThings] = useState([])
----

But it is RECOMMENDED to import the entire `react` package, and use the `React`
namespace for all React-related imports. This makes it easier to identify
React-related code in your project.

[source,jsx]
----
import React from "react"

/* Usage: */
const [things, setThings] = React.useState([])
----

For this reason, the `import React from "react"` pattern is still RECOMMENDED
for all React components.
