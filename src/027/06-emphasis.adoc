= Emphasis

Use asterisks (`*`) for emphasis, not underscores (`_`). Underscores in the
middle of a word are not interpreted as emphasis by some processors, while
asterisks are reliable in all positions.

```
*italic text*
**bold text**
***bold and italic text***
```

For GFM, strikethrough is written using two tildes (`~~`):

```
~~struck-through text~~
```

Emphasis SHOULD be applied to words or short phrases, not to entire paragraphs.
Do not nest emphasis unnecessarily.

For guidance on using emphasis appropriately in technical writing, see
*link:../026/README.adoc[TS-26: Technical Writing Style Guide]*.
