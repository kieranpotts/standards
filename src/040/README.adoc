= TS-40: CSS
:toc: macro
:toc-title: Contents

This technical standard specifies a CSS architecture — a design methodology
built on user-land conventions such as BEM, SMACSS, and OOCSS — that helps
control the cascade and produce maintainable, scalable user interfaces.

It defines naming conventions and a system for separating the different concerns
of a web interface: layout, elements, components, and modifiers.

The CSS architecture described herein applies equally whether stylesheets are
hand-written, compiled from a preprocessor like Sass or Less, or generated by a
CSS-in-JS framework.

== References

* https://bradfrostweb.com/blog/post/atomic-web-design/[Atomic Design — Brad
  Frost]: A methodology for thinking about interfaces as a hierarchy of
  progressively more complex objects.

* https://bem.info[Block Element Modifier (BEM) — Yandex]: A widely adopted
  class naming convention.

* http://smacss.com[Scalable and Modular Architecture for CSS (SMACSS) —
  Jonathan Snook]: A style guide covering base, layout, module, state, and theme
  rules.

* https://suitcss.github.io[SUIT CSS — Nicolas Gallagher]: A class naming
  convention combined with extended CSS syntax.

* https://github.com/stubbornella/oocss[Object-Oriented CSS (OOCSS) — Nicole
  Sullivan]: One of the earliest widely adopted web design methodologies,
  published 2009.

* https://cssguidelin.es[CSS Guidelines — Harry Roberts]: A high-level advice
  document for writing sane, manageable CSS.

* https://google.github.io/styleguide/htmlcssguide.html[Google HTML/CSS Style
  Guide]: Formatting and naming conventions for HTML and CSS.
