= TS-46: Distributed Data and Caching
:toc: macro
:toc-title: Contents

Most caching bugs don't come from Redis or Memcached, or whatever technology is used to implement the cache. They come from bad cache design.

This technical standard covers best practices for implementing caching in software systems. This is general guidance, not specific to any particular caching technology or application layer.
