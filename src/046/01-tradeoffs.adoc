= Caching tradeoffs

Caching is the most common form of distributed data, so we begin there. The same
tradeoffs apply, in different proportions, to any data we choose to distribute.

There are lots of costs to caching, including:

* Harder debugging and code profiling.
* Users see outdated information.
* Increased memory footprint (because you just move resource utilization, you
don't actually reduce it).
* Increased system complexity.

We must have clear reasons to implement caching layers in our applications, and
these must be clearly defined and documented.
