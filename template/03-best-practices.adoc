= Best practices and anti-patterns

== Do

* *Plan ahead.* Lorem ipsum dolor sit amet, consectetur adipiscing elit. See
  <<overview>>.

* *Preserve the source.* Donec pretium posuere tellus, vel posuere dui
  hendrerit.

* *Design for idempotency.* A failed or interrupted operation MUST be resumable
  by re-running it.

* *Validate before proceeding.* Integer auctor ipsum a tortor tincidunt.

== Don't

* *Don't combine independent operations.* Coupling them produces a single
  failure with the worst-case rollback profile of both.

* *Don't trust a single signal.* A passing check proves completeness only.
  Validation MUST include a correctness check.

* *Don't ship an irreversible step unmarked.* Irreversible steps MUST be
  identified, gated on prior validation, and approved explicitly.
