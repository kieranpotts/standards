# Agent skills

Agent skills for maintaining these technical standards.

| Skill                                    | Summary                                                                  |
| ---------------------------------------- | ------------------------------------------------------------------------ |
| [deep-dive](./deep-dive/README.md)       | Review a standard in depth, then work the resulting plan tier by tier.   |
| [gap-analysis](./gap-analysis/README.md) | Check a standard for coverage gaps against external reference resources. |

See also the `fix-xrefs` skill in the website repo. It validates cross-references
internally within this Antora module, and also between this and other Antora
modules that are imported into the website build playbook.
