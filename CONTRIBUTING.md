# Contributing

These technical standards are living documents. To make changes to a technical standard, or to create a new one, use the normal pull request workflow via GitHub.

To create a new standard, copy the [`template/`](template/) directory into `src/` under the next available zero-padded number, then replace the lorem-ipsum content. The template is a representative entry that demonstrates the established structure and conventions. See the [style guide](docs/style-guide.md) for the normative rules.
